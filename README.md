## Description

**Xintinglei Extras** adds **18 drinks and four types of placeable 3D mooncakes**, bringing a little fun to everyday survival and festive decorations.

### Four Distinct Mooncake Varieties

- **Ordinary Mooncake**: Golden pastry with traditional patterns and copper-inspired oxidation and waxing mechanics.
- **Snow Skin Mooncake**: A pale mooncake ready to eat after crafting—no baking required.
- **Yunnan Ham Mooncake**: Rounded pastry with a savory filling.
- **Hong Kong Lava Custard Mooncake**: Golden pastry with a molten custard center.

### Enjoy Them or Display Them

Ordinary, Yunnan Ham, and Lava Custard Mooncakes must first be crafted as raw mooncakes, then baked in a furnace.

Place a whole mooncake and right-click it with a sword to cut it into four pieces. Right-click with an empty hand to pick up a piece, then eat it while holding it. Matching pieces can also be placed together, with up to four pieces in one block space.

Only Ordinary Mooncakes oxidize. Apply honeycomb to preserve their current appearance, use an axe to remove wax or reverse one oxidation stage, or let nearby lightning restore them. Waxed mooncakes must be unwaxed before eating. The other three varieties do not oxidize.

### Different Drinks for Different Occasions

Coffee, tea, juice, soda, and other drinks each have different effects. Some provide temporary buffs, while others also come with side effects. Check the item tooltip before drinking.

### Installation

For **Minecraft Java 1.21.4 / Fabric**. Requires **Fabric API**, **Fabric Loader 0.16.14+**, and **Java 21+**.

For multiplayer, install the mod on both the client and server.

## 介绍

**Xintinglei Extras** 加入了 **18 款饮料与四类可摆放的立体月饼**，能为生存日常和节日装饰增添一些趣味。

### 四款月饼，各有特色

- **普通月饼**：金黄饼皮与传统纹样，拥有铜块风格的氧化和涂蜡玩法。
- **冰皮月饼**：浅色冰皮，合成后即可食用，无需烘焙。
- **滇式云腿月饼**：圆润酥皮，搭配咸香馅料。
- **港式流心奶黄月饼**：金黄外皮，内藏流心奶黄。

### 可以吃，也可以摆

普通、云腿和奶黄月饼需要先制作生坯，再放入熔炉烘焙。

摆放整块月饼后，用剑右键即可切成四份。空手右键可以拿起一块，拿在手中食用；同款切块也能放到一起，一个位置最多放置四块。

只有普通月饼会氧化。使用蜜脾涂蜡可以保持当前外观，用斧头可以刮蜡或退回一个氧化阶段，附近的雷击也能让它恢复。涂蜡后需先刮蜡才能食用，其他三款月饼不会氧化。

### 不同场合，不同饮料

咖啡、茶、果汁、汽水等饮料各有不同效果。有些提供短暂增益，有些也伴随副作用，饮用前可以查看物品提示。

### 安装说明

适用于 **Minecraft Java 1.21.4 / Fabric**，需要 **Fabric API**、**Fabric Loader 0.16.14+** 和 **Java 21+**。

多人游戏需客户端与服务端同时安装。
